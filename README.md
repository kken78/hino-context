# hino-context

滋賀県日野町の計画・予算・議会の公開資料を、人と生成AIが論点ごとに引くための、定義・決まり・対応を管理する場所です（非公式）。画面の名前は「論点ノート」です。

町が公開している資料だけを材料にし、どの記載も原典のページや発言までたどれるようにします。評価や結論は書きません。目的と作りは [docs/hoshin.md](docs/hoshin.md)、作業の手順は [CLAUDE.md](CLAUDE.md) にあります。

これは個人による提案と試作で、日野町や日野町議会の公式の物ではありません。内容は、会議録の原本や各資料の原典で確認してください。

前のリポジトリ（経過と確定済みの台帳）は [hino-ronten](https://github.com/kken78/hino-ronten) にあります。
